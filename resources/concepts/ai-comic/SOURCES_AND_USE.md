# ai_comic概念的来源与使用

本包以[项目概念](CONCEPT.md)为主入口，按实际问题展开[管线概念](pipeline/CONCEPT.md)、案例与原件。概念库提供维护和读取位置；本项目的目标、实际产物与用户纠正决定怎样使用和修正这些理解，不由目录层次替项目作裁决。建立日期为2026年10月4日。

## 读取和使用

先读取本库的[概念工作方法](../../concept-workflow/SKILL.md)，再读项目主入口中的[最终目标与后续工作的依据](CONCEPT.md#最终目标与后续工作的依据)和当前任务涉及的真实情境。围绕当前任务选择相关关系和原件，需要时进入管线子概念；不要求每次读完全部历史，也不把主入口的短定义当作读完了概念。

后续选择和重要阶段回看，要能说明当前行动推进什么能力、实际证据是否支持，以及新纠正影响什么。目标由项目主概念维护，不另建重复正文；计划可以调整、抛弃或结束，不能据其完成情况认定目标达成。目标确认、当前能力和执行授权是三件不同的事：2026年10月8日先记录目标，随后用户提出“建立目标，然后开干”，当时才建立active目标并开始实施；10月13日用户认可整体取舍方向，要求完善概念与计划并创建目标。当前目标状态与实际执行以[项目目标与证据](D:/Models/ai_comic/docs/ACTIVE_GOAL_EVIDENCE.md)的新记录及目标工具为准，不能从这些历史日期推断服务正在运行。旧具体实验和拒收任务没有自动恢复。

同一个对象可以在不同关系中被使用。f17的画法价值、原任务偏离和实际编码条件要一起辨认；海岸失败图可以帮助认识错误怎样被保留，却不因此继续成为创作底图。查明用户纠正的对象与用途后，重看受到影响的理解，不因为文件有链接就全局推倒。

例如，可向接收者明确提出：

> 读取 F:/Models2/concept/concept-workflow/SKILL.md 与 F:/Models2/concept/concepts/ai-comic/CONCEPT.md。围绕幽灵鲨海岸任务，打开相关原图与输入，解释当前简陋感中哪些是观察、哪些仍是假说；需要时展开 pipeline/CONCEPT.md，提出后果不同的表现选择。保留原句、角色身份与用户评价范围，不预定模型链，也不把未生成方案当作已验证结果。当前只讨论，不启动服务或提交生图。

这是按文件路径读取并使用概念的入口，不是自动安装的skill，也不是生图程序的运行时检索接入。接收者能复述文字或找到文件，仍不能证明它能可靠作出新判断；需要用具体情境、纠正与实际作品继续验证。
