# 创作概念资源

`concepts` 保存本项目创作工厂会读取的四份完整概念原文：项目理解、管线理解、来源与使用说明，以及 concept 工作方法。应用默认从随源码附带的资源读取，也可在模型接入页指定另一份同结构资源根目录。

这些原文包含项目形成过程、用户纠正、不同解释与原件引用，不是将创作简化为几个风格标签。历史实验和个人任务仍由原件引用指向，未将大量生成图、评价库或本机工作目录打包进源码。外部原件链接不是安装前置条件；应用不会自动跟随链接、下载资源或扫描其他磁盘。

公开资源为发行时的完整快照。更新概念时，应维护完整内容与对应来源，再更新本项目快照，不以零散摘要替换正文。模型接收到原文不等于已经理解，仍需要结合实际画面和用户反馈作判断。
